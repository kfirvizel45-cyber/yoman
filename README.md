# יומן חכם

אפליקציית יומן אישית מעל יומן גוגל. מתקינים אותה במסך הבית באייפון.

## העלאה ל־GitHub Pages (חינם)
1. פתח חשבון ב־github.com.
2. צור מאגר חדש (New repository) בשם `yoman`, ובחר Public.
3. לחץ "uploading an existing file" וגרור לשם את כל הקבצים והתיקיות מה־zip.
4. היכנס ל־Settings ← Pages. תחת Source בחר `main` ולחץ Save.
5. אחרי דקה האפליקציה תהיה זמינה בכתובת `https://<שם-המשתמש>.github.io/yoman/`

## חיבור ליומן גוגל (פעם אחת, כ־15 דקות)
ההוראות המלאות, וכפתורי העתקה לכתובות שצריך להדביק, נמצאים במסך ההגדרות של האפליקציה.

## התקנה באייפון
פותחים את הכתובת בספארי ← לוחצים על כפתור השיתוף ← בוחרים "הוסף למסך הבית".

## מבנה הקבצים
- `js/parser.js` — מפענח העברית
- `js/scheduler.js` — אלגוריתם שיבוץ זמני ההכנה
- `js/school.js` — מערכת השעות ושעות הצלצולים
- `js/gcal.js` — החיבור ליומן גוגל, ומצב הדגמה
- `tests/` — הבדיקות. להרצה: `node tests/parser.test.mjs`
